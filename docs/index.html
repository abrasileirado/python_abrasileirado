Módulo Python

python_abrasileirado 🐍

Biblioteca Python para validação, formatação e geração de objetos de domínio brasileiros imutáveis (CPF, CNPJ, CEP, IE, etc.).

Instalação

pip install abrasileirado

Uso Básico

Exemplo de validação de CPF e CNPJ:

from abrasileirado import CPF, CNPJ

# Validação e formatação de CPF
cpf = CPF("12345678909")
print(cpf.eh_valido)  # True/False
print(str(cpf))       # "123.456.789-09"

Desenvolvimento Local

Para contribuir ou testar localmente, utilize a orquestração do repositório privado workspace:

cd ~/projetos/PESSOAL/abrasileirado/workspace
./abrasileirado cli python
